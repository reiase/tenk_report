# 证据、数据与引用规范

## 可追溯链路

报告中的关键结论应形成以下链路：

```text
结论 → 图表或表格 → 处理脚本 → 汇总数据 → 原始日志 → 运行配置与版本
```

如果原始日志因容量或保密要求不能入库，应记录存储位置、访问方式、内容哈希、保留期限和责任人。

## 数据分级

提交前按组织规则确认数据分级。若尚无内部规则，至少区分：

- 可公开：可以进入公开仓库和最终报告；
- 内部：只可进入受控仓库，发布时需聚合或脱敏；
- 受限：不得提交，仓库只保留引用标识和授权访问方式。

严禁提交密钥、令牌、个人信息、内部地址、未脱敏客户数据或受限日志。脱敏应保持指标统计意义，并在报告中说明处理方式。

## 实验数据

- 每次运行使用唯一实验编号，格式见 [实验记录](../experiments/README.md)。
- 原始数据不可手工覆盖；清洗与聚合结果写入独立文件。
- 表格必须给出单位、时间范围、样本数量和缺失值处理。
- 比较实验应保存基线与实验组的完整配置差异。

## 引用

外部资料在 [参考资料](../references/README.md) 中分配稳定编号，例如 `[R001]`。正文写法示例：

```markdown
通信算法的定义见 [R001](../references/README.md#r001)。
```

优先引用标准、论文、官方文档和可长期访问的原始来源。记录标题、作者或机构、发布日期、访问日期、链接和具体支撑内容。
