# EXP-010：A3 与 C550 资源池健康准入

## 目的

导入 A3 两个 4,096 卡批次、A3 备机和 C550 2,336 卡候选池的健康检查汇总，区分单卡正确性、ECC/RAS、性能候选、Pairwise 定位和目标训练拓扑通过五种证据，形成可审计的准入漏斗。

## A3 筛查结果

来源汇总了两个 256 节点、每节点 16 个逻辑 NPU 的独立 Job，以及一个 6 节点备机 Job。仓库没有导入三轮成员清单，不额外推断它们是否完全互斥。

| Job | 覆盖 | GOOD | BAD | CONTENDED | SLOW | 证据说明 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| A3-4096-r1 | 4,096 | 4,093 | 2 | 1 | 0 | 两张 BAD 为 GEMM correctness 异常；另有 1 个节点 MTU 不一致 |
| A3-4096-r2 | 4,096 | 4,093 | 0 | 3 | 0 | CONTENDED 表示计时质量不足，不按慢卡处理 |
| A3-reserve | 96 | 96 | 0 | 0 | 0 | 静态、单节点、CARD_SCREEN 与 Pairwise 均通过 |

r1/r2 的单节点 dynamic-suite 均为 256/256 PASS。r1 的 Pairwise 为 256 PASS、0 SUSPECT、0 FAIL，物理超节点链路覆盖 8/8；r2 的节点定位为 256 PASS，物理 Pairwise 链路完成 11/11。r1 在 Scale64/128 出现结果传输失败和不同首发节点的 `HcclGetRootInfo error code 7`，清理或定向复测后 Final256 通过。首发节点不固定，这些事件按通信路径事件登记；固定 RDMA 硬件故障由定向复测确认。

两轮 stall-screen 分别记录 3,427 KEEP / 234 SUSPECT / 435 HOT 和 3,308 KEEP / 293 SUSPECT / 495 HOT。HOT/SUSPECT 是同步循环中的前向进展观察项，不等于温度告警或坏卡。备机轮次唯一重复观察项在 180 秒独占复测中恢复为 KEEP、0 次 Stall，因此仍按并发运行时观察处理。

## C550 筛查与 2,048 卡拓扑

C550 先对 292 节点、2,336 张卡执行全量筛查，再选择 256 节点进入 2,048-rank 训练拓扑验收。

| 类别 | 数量 | 证据语义 |
| --- | ---: | --- |
| correctness BAD | 1 张卡 | GEMM 最大相对误差 0.0552，属于明确正确性异常 |
| SDC-SUSPECT | 3 张卡 | 独立复测，与已确认 BAD 分开管理 |
| DEAD | 7 张卡 | 来源记录累计不可纠正 ECC；不是本轮新增错误率 |
| ECC 配置异常 | 1 个节点 | 至少一张卡 ECC 被关闭，静态准入阻断 |
| HBM SLOW | 70 张卡 / 9 个节点 | 1,045.05--1,054.11 GB/s，中位数 1,050.28 GB/s；全体有效中位数 1,488.66 GB/s |
| 单机通信性能候选 | 1 个节点 | 11 个 1/2 GiB case 经 3-batch 复测仍低于 cohort 门限 |
| 节点间通信候选 | 1 个节点 | 与多个伙伴在 All-Reduce 运行期复现 RDMA/MCCL completion error |

stall-screen 覆盖 2,336/2,336 卡，结果为 2,112 KEEP、115 HOT、109 SUSPECT，无失败 Pod。Pairwise 最终有效汇总为 296 个 group：292 PASS、4 FAIL；节点定位为 291 PASS、1 SUSPECT。伙伴节点在其他配对中通过，因此通信异常收敛到单节点候选，最终硬件根因由端口计数、驱动与 MCCL 日志共同确认。

训练拓扑中 Scale16/32/64/128 和 Final256 均通过，Final256 完成 2,048-rank 集合通信。Scale8 首轮存在 6 个 TIMEOUT，定向复测记录 4/4 PASS；这证明筛选后的 256 节点至少完成过目标拓扑通信验收，不证明 Megatron 长稳、扩展效率或训练成功率。

## 状态解释

- `BAD`、`DEAD`、`SDC-SUSPECT`、`SLOW` 和 `CONTENDED` 保持来源原义，不合并成一个“坏卡率”。
- 累计 ECC 值只证明历史计数存在；没有测试前后增量时，不报告本轮故障发生率。
- Pairwise 或 topology 的结果传输失败与 collective 失败分开统计；复测通过不删除首轮异常。
- A3 两个 4,096 卡 Job 和 C550 2,336 卡候选池属于不同资源池、不同检测实现与不同 cohort，不做通过率排名。

## 适用范围

- A3 来源支持两个 4,096 卡批次和 96 卡备机的分层检查汇总；8,192 卡唯一覆盖率由受控成员清单复算。
- C550 已形成 2,336 卡候选池筛查和筛选后 2,048 卡拓扑通过的文档级证据；训练扩展曲线与长稳进入独立实验体系。
- 设备级异常数不等于节点排除数；一个节点包含多张卡，且性能候选、配置异常和硬失败的处置不同。
- 生产健康率、MTBF、误隔离率和训练成功率由成员快照、维修闭环和统一统计窗口共同生成。
