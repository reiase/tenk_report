# EXP-004：10240 卡异构资源池加权验收

## 指标性质

本实验按验收材料定义，将 8192 张 A3 与 2048 张 C550 的每卡等效算力（ECP）按设备数量加权，比较共同运行窗口与各平台独立基线。

该指标是**异构资源池加权验收指标**，评价 10,240 卡纳管资源池在共同窗口内相对各自基线的有效产出；A3、C550 各自的吞吐与扩展曲线仍分别报告。

## 数据与共同窗口

新万卡日志包 `training_full_log2.tar.gz` 包含 4 个 A3 训练组和 4 个 C550 训练组：

| 平台 | 训练组 | 每组卡数 | 总卡数 | 共同窗口内每组步数 |
| --- | ---: | ---: | ---: | ---: |
| A3 | group 0--3 | 2048 | 8192 | 239 |
| C550 | group 4--7 | 512 | 2048 | 120 |

日志前段存在通信超时与重启，未进入正式计算。八个组共同连续窗口为 `2026-08-15 21:39:18` 至 `2026-08-16 10:49:54`，共 47,436 秒（13.18 小时）。窗口内所有组的 skipped 和 NaN iteration 均为 0。

补充编排材料 [S009](../../references/project-sources.md#s009) 记录了 8 个训练组与 64 个共享参数服务器：A3 group 0--3 每组 2,048 张卡，使用 `TRAIN_ITERS=500`、`PS_SYNC_STEP=50`；C550 group 4--7 每组 512 张卡，使用 `TRAIN_ITERS=100`、`PS_SYNC_STEP=10`。参数服务器位于一个 A3 组，训练组按各自周期同步。该结构进一步确认这是八组协同运行，不是 10,240 张卡处于同一 TP/PP/DP/EP 或 collective 域。

## 计算

共同窗口聚合得到：

| 平台 | 独立基线（TFLOPS/卡） | 万卡窗口 ECP（TFLOPS/卡） | 权重 |
| --- | ---: | ---: | ---: |
| A3 | 108.5571 | 101.6508 | 0.8 |
| C550 | 60.9000 | 51.0364 | 0.2 |

混合窗口加权 ECP 为：

\[
ECP_{mix}=0.8\times101.6508+0.2\times51.0364=91.5279.
\]

独立基线加权 ECP 为：

\[
ECP_{ideal}=0.8\times108.5571+0.2\times60.9000=99.0257.
\]

因此验收加权指标为：

\[
E_{weighted}=\frac{91.5279}{99.0257}=92.4284\%.
\]

正式取两位小数为 **92.43%**。用固定单步计算量 20,173.53 TFLOP/卡/step 独立复算得到 92.42%，差异为 0.008 个百分点。

## 适用范围

- 92.43% 对应 13.18 小时共同连续窗口，用于异构协同验收；目标步数完成率和端到端训练效率另行评价。
- C550 60.90 基线采用 3 步材料中的末步口径；生产基线建议补充 20--30 个稳态步并冻结均值/中位数口径。
- A3 与 C550 的单平台结果分别报告；91.5279 TFLOPS/卡作为混合窗口加权值使用。
- A3 与 C550 训练组的目标步数和参数服务器同步周期不同；共同窗口聚合评价资源池协同产出，不合并八组 step 语义。
- 本实验记录补齐两个独立基线的任务、窗口和公式，验收口径随统稿评审一起冻结。
