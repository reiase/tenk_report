# 评测方法与实验设计

## 研究问题

将每个实验对应到一个可回答的问题，例如扩展效率、吞吐瓶颈、精度一致性或故障恢复时间。

## 指标定义

为吞吐、时延、MFU、扩展效率、有效训练时间占比和能耗等指标给出公式、单位、采样窗口及排除规则。

## 基线与变量控制

说明基线系统、唯一自变量、固定配置、预热、重复次数和随机性控制。

## 数据处理

记录异常值规则、缺失值处理、聚合方式、置信区间和图表生成流程。

## 实验索引

在 [实验记录](../experiments/README.md) 中登记每次实验，并在此处按研究问题汇总。

## 有效性威胁

讨论硬件批次、软件版本、工作负载代表性、测量误差和结果外推限制。
