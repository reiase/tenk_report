# 实验记录

每项实验使用稳定编号，并按照统一实验模板记录。建议结构：

```text
exp-001-scaling/
├── README.md
├── config/       # 脱敏后的运行配置
├── scripts/      # 运行与处理脚本
├── summary/      # 可入库的聚合数据
└── figures/      # 由数据生成的图表
```

大型原始日志通常不直接提交 Git；在实验 README 中记录受控存储位置、哈希和保留期限。

## 计划实验族

以下条目是技术报告中的验证槽位，不表示实验已经完成。实际运行后应拆成独立、稳定编号的实验记录，并绑定配置摘要与原始证据位置。

| 建议编号 | 研究问题 | 最低比较条件 | 主要输出 |
| --- | --- | --- | --- |
| EXP-016 | 低频 outer synchronization 能否在目标模型上保持优化效率 | 同数据顺序或等价抽样、等 token/FLOPs/墙钟预算、同步数据并行基线 | 质量曲线、通信字节、outer update 数、有效训练进度、island 间差异 |

| EXP-018 | 触发式取证能否在有界扰动下保全跨 rank 运行时现场 | 固定异常注入、目标 rank/函数/变量与时间窗、无观测和不同采集强度对照 | 火焰图路径与覆盖、变量状态矩阵、崩溃证据完整率、watchdog 快照、step P50/P95/Max 增量 |
