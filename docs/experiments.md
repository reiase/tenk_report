# 实验记录

每项实验使用稳定编号，并按照统一实验模板记录。建议结构：

```text
exp-001-scaling/
├── README.md
├── config/       # 脱敏后的运行配置
├── scripts/      # 运行与处理脚本
├── summary/      # 可入库的聚合数据
└── figures/      # 由数据生成的图表
```

大型原始日志通常不直接提交 Git；在实验 README 中记录受控存储位置、哈希和保留期限。
