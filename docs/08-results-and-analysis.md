# 结果与分析

## 规模扩展

呈现不同规模下的吞吐、扩展效率和资源利用率，并明确强扩展或弱扩展口径。

## 端到端训练性能

同时报告稳态性能和包含启动、数据等待、检查点及故障恢复的端到端性能。

## 稳定性结果

按时间范围和故障分类汇总有效训练时间、故障频率及恢复成本。

## 瓶颈分析

区分测量结果与原因推断。每个原因推断应给出支持证据和可证伪条件。

## 消融与对比

说明对比是否保持模型、批大小、精度、数据和软件版本一致。

## 结果边界

列出不可直接外推的模型、规模、版本和运行环境。
