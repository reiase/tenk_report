## 当前技术主线

报告围绕两个独立硬件资源池和三项核心工程工作展开：

1. **筛卡与健康检查**：建立节点准入、运行中巡检、异常隔离和恢复后复验闭环。
2. **Megatron 调优**：针对两套软硬件栈分别完成算子、并行、显存、通信和调度优化。
3. **线性加速比控制**：从小规模基线逐级放大，以扩展效率作为每一级扩容的准入指标。

两类加速卡的性能和扩展效率分别建模、分别报告，不将异构卡数简单相加后计算单一吞吐指标。

观测不是第四条独立业务主线，而是贯穿三项工作的证据层：常驻路径保存低成本训练坐标和趋势，异常窗口再下钻到 module、collective、通信 task、kernel 或 stack；所有跨 rank 结果同时披露覆盖、丢弃、partial 和开销。

## 当前证据成熟度

- 已复核：A3 1024 卡调优、4096 卡通信消融、1024→4096 卡 7 步弱扩展，以及 10240 卡八组共同 13.18 小时的加权验收计算。
- 部分通过：A3 8192 卡 r2 已完成建组并进入 iteration 7；尚未形成完整 30 步、长稳、检查点与恢复结论。
- 文档级证据：A3 2048 die 配置搜索中 TP2/PP16/uniform1 的 MFU 为 33.4%；200B Dense 在 1,024 die 完成 800/800 step、1T MoE 在 2,048 die 完成 500/500 step。两类材料均缺少足以独立复算的逐步原始数据。
- 根因进展：A3 Stall 已在来源报告中闭环到 IPVS `estimation_timer` 阻塞 NPU CQ tasklet；完整 ftrace 待归档。C550 direct dispatch 为厂商缓解证据，观察时长和原始 gap 待补。
