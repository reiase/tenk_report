# 异构万卡训练系统：可靠性、通信与可观测性技术报告

## 报告定位

本报告面向机器学习系统工程师，研究异构万卡训练中的三个相互关联的问题：

1. 设备完成基础功能测试，为何仍不足以证明其适合参与大规模同步训练；
2. 低概率局部异常如何经并行组、同步边界和长时间运行转化为系统级资源损失；
3. 如何在控制观测扰动的前提下，获得支持定位、复验和资源决策的充分证据。

报告以 A3 与 C550 两个独立资源池为研究背景。硬件能力、通信拓扑和软件栈分别建模；正确性、可持续能力、前向进展、概率覆盖和证据质量采用统一方法定义。平台案例用于解释系统机制及其影响范围，不用于构造缺少同口径实验的跨硬件排名。

## 论证结构

全文按照“系统问题—执行模型—故障与传播—测量与推断—案例与影响—结论与边界”展开：

1. 首先定义资源池、软硬件执行边界和训练同步模型；
2. 随后分析计算、HBM、功率热状态、SDC、ECC/RAS 和前向进展；
3. 再讨论低开销 fleet-wide 观测、联邦查询和角色化诊断；
4. 通过计时、概率、反事实与干预实验约束推断强度；
5. 最后将 A3、C550 案例放回训练拓扑、资源时间和适用边界中解释。

两条次级技术线索贯穿相关章节：

- **分层检测与 probing**：由低侵入常驻事实出发，经 rank-role 热力图和联邦查询定位异常集合，再以分布式火焰图、Python 状态 watch、通信进行中快照和 fatal error 现场保全形成窄窗口证据。正文以触发式取证和证据归并的通用方法为主体，Probing 仅作为参考实现证据。
- **低通信与弹性训练**：由严格 BSP 的同步传播出发，讨论训练岛、本地优化、低频 outer synchronization，以及 Parameter Server 作为全局状态协调层的组合条件。该部分属于行业研究方向，不替代当前同步训练基线。

当前已形成单卡计算/HBM/SDC、ECC/RAS、异步计时、长窗前向进展、拓扑感知通信、联邦查询和分布式诊断的方法证据；A3 与 C550 同步长尾属于已登记案例证据。目标资源池资产快照、冻结版本、逐事件时间线和目标规模训练结果仍需补齐。低通信弹性训练目前属于研究设计，须以同步训练为对照验证收敛、token accounting、恢复语义和资源效率。

每个数字只保留一个权威位置：原理章节解释机制，方法章节定义测量，案例章节保存具体数据，其他章节通过引用建立关联。
