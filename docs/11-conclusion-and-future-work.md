# 结论与后续工作

## 结论

- A3 上的 Qwen3-200B 已形成可追溯的 1024 卡调优、4096 卡通信消融和 1024→4096 卡短程弱扩展证据。严格对齐配置并保留全部 iteration 6--12 后，弱扩展效率为 **94.26%**。
- 8192 卡 r1 暴露出分布式优化器 Gloo 全互连建组的规模化阻塞；r2 使用 `--disable-gloo-group` 后完成建组并进入 iteration 7。该结果证明修正方向有效，但还不是 8192 卡完整性能或长稳验收。
- 8192 张 A3 与 2048 张 C550 的八组日志在共同 13.18 小时窗口内得到 **92.43%** 加权 ECP 保留率。该值适用于验收材料定义的资源池加权口径，不代表 10,240 卡运行同一个同步训练作业。
- 现阶段最可靠的资产不是单个最高吞吐数字，而是“配置不变量—稳定实验编号—统计窗口—聚合数据—原始证据哈希—结论边界”的可复核链路。

## 已知限制

- EXP-003 仅有 7 个评分步，没有随机化 placement 重复、检查点和端到端时间分解。
- EXP-004 的 C550 独立基线只有 3 个有效 iteration，并采用第 3 步 60.90 TFLOPS/卡；92.43% 因此仍是有限证据下的验收点估计。
- 8192 卡 r2 的代表日志只到 iteration 7，不能报告 30 步完成率、稳态 MFU 或长稳成功率。
- C550 2048 卡独立分池准入与扩展曲线尚未完成；健康检查、RAS、观测开销和成员质量收据也未与主性能实验完全闭环。
- MoE、1T 模型、offload 和正式 mid-training 试验尚未形成同口径可比较结果，不进入本版主结论。

## 后续工作

| 工作项 | 预期价值 | 前置条件 | 验证标准 | 优先级 |
| --- | --- | --- | --- | --- |
| 重跑 C550 1024 卡独立基线 | 关闭 92.43% 的最大统计缺口 | 冻结当前模型、配置和理论峰值口径 | 至少 20--30 个稳态步，预注册均值/中位数与排除规则 | 高 |
| 完成 A3 8192 卡正式验收 | 从 startup pass 升级为生产结论 | 保留 r2 修正、完整成员与 placement 快照 | 完整短程、长稳、检查点恢复、skipped/NaN=0 和质量收据 | 高 |
| 完成 C550 2048 卡分池扩展 | 建立独立硬件曲线 | 1024 卡稳态基线和 C550 准入通过 | 同口径弱扩展、重复轮和端到端结果 | 高 |
| 随机化复测 EXP-001/002 候选 | 区分真实收益与时间/placement 漂移 | 冻结资源组、顺序和外部负载 | 交错 A/B、重复基线、置信区间与 NO_DATA 补齐 | 高 |
| A3 HCCL ABI 与观测开销闭环 | 让通信归因与主结果可信 | 冻结 CANN/HCCL、shadow/on-off 基线 | 字段抽样一致、覆盖完整、P50/P95/Max 开销达标 | 中 |
| C550 原生通信观测适配 | 补齐 API 层以下证据 | MCCL callback/ABI 与厂商文档 | 与 Torch API 和厂家工具同窗对照 | 中 |
| 冻结 MoE/1T 工作负载后再调优 | 避免把启动试错写成性能结论 | 模型身份、权重、数据、并行和 offload 配置可审计 | 同配置基线、逐项 A/B、显存/吞吐/稳定性联合报告 | 中 |
