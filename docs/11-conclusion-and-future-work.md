# 结论与持续优化

## 总体结论

项目完成了 10,240 张国产加速卡训练基础设施的统一纳管与分资源池技术体系建设。A3 与 C550 分别建立健康准入、训练适配、通信优化和性能评价基线，并通过 8 个训练组与 64 个参数服务器实现万卡协同运行。

项目工作的核心价值是将大规模硬件资源转化为可测量、可调优、可定位和可复现的训练能力。十四组实验覆盖了从设备筛查到模型训练、从并行配置到通信根因、从短程性能到工程资产归档的完整链路。

## 核心工程结论

1. **健康准入决定有效规模**：万卡训练首先需要形成质量一致的设备和节点集合。correctness、SDC、HBM、通信性能和拓扑状态分层处理，能够减少单点异常对同步训练的全局放大。

2. **并行策略需要联合搜索**：TP、PP、DP、EP、VPP、GBS 和重计算共同决定算子效率、显存、流水线气泡与通信暴露。TP2/PP16 的 Dense 结果表明，中等 TP 与 PP 组合在当前 A3 拓扑上实现了更好的整体平衡。

3. **拓扑是性能配置的一部分**：相同并行参数在不同 rank order、逻辑超节点和跨域出口分布下会形成不同通信路径。物理 placement、rank mapping 和通信组定义应与训练配置一并固化。

4. **启动、稳态与长周期运行分层评价**：8,192 卡 Gloo 建组修正、4,096 卡稳态吞吐、800/500 step 功能运行和协同窗口 ECP 分别评价系统的不同能力，组合后形成完整的规模化运行画像。

5. **前向进展需要跨层定位**：A3 Stall 证明主机软中断可以阻塞设备完成通知；C550 的单卡派发事件与集合通信尾延迟则对应不同诊断层。step、设备 event、collective 和系统 trace 的统一时间坐标显著缩短根因定位路径。

6. **控制面效率直接转化为训练卡时**：本地热库、执行与回收解耦、Pairwise 波次优化和独立超时语义，使单轮 64 节点健康检查减少约 184.9 加速卡时，提升了扩容与周期巡检效率。

## 持续优化路线

| 方向 | 优化内容 | 评价指标 |
| --- | --- | --- |
| A3 目标规模运行 | 固化 8,192 卡成员、placement、检查点与恢复流程 | 稳态吞吐、长周期成功率、恢复时间 |
| C550 分池扩展 | 建立 1,024→2,048 卡训练扩展曲线 | 每卡吞吐、扩展效率、通信尾部 |
| Dense 并行网格 | 围绕 TP2/PP16 拆分 TP、PP、VPP 与重计算变量 | MFU、step time、显存、CV |
| 1T MoE 扩展 | 优化 EP All-to-All、CPU offload、重计算与 placement | tokens/s、专家负载、通信暴露 |
| A3 Stall 系统治理 | 完成 IPVS/IRQ CPU 隔离与同条件回归 | 事件率、P99 gap、训练长尾 |
| C550 派发与网络 | direct dispatch 与端口/交换机遥测联动 | Stall 事件率、QP 状态、AllReduce P99 |
| 健康检查效率 | 同节点交错运行与阶段耗时基线 | 墙钟、卡时、P50/P95/Max、结果完整性 |
| 通信观测 | 完善 HCCL/MCCL 原生事件与网络计数器关联 | rank 覆盖、采样开销、定位时长 |
| 工程归档 | 主快照、增量和大对象分层管理 | 完整性、恢复时长、跨域副本状态 |
