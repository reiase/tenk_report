# 稳定性、容错与可观测性

## 稳定性指标

定义有效训练时间占比、作业成功率、平均故障间隔、平均恢复时间等指标及分母。

## 检查点与恢复

说明保存频率、写入时延、一致性、保留策略和恢复演练结果。

## 可观测性

列出主机、卡、网络、通信、框架和业务指标，以及日志与追踪的关联方式。

## 故障处置闭环

描述检测、定位、隔离、恢复、复盘和预防的责任边界及自动化程度。
